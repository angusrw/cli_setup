# Common non-approved → approved substitutions

A working reference of frequent swaps when rewriting into Simplified Technical English.
This is **not** the full ASD-STE100 Dictionary — it covers the words that come up most in
general technical prose. When the official Dictionary or a project term list disagrees with
this table, follow the official source.

Keep the approved word to a **single meaning and part of speech**. Where a common word has
several meanings, the row shows which meaning to replace.

## Verbs and actions
| Avoid | Use |
|---|---|
| commence, initiate | start, begin |
| terminate, cease | stop, end |
| utilize, employ (= use) | use |
| activate (general) | start, switch on, energize |
| deactivate | stop, switch off, de-energize |
| depress (a button) | push, press |
| verify, ensure, confirm | make sure |
| ascertain, determine | find, calculate, measure |
| obtain, acquire | get |
| require | need |
| permit | let, allow |
| perform, carry out, conduct | do |
| accomplish, execute | do |
| modify, alter | change |
| assemble (general) | build, connect, install |
| fabricate | make, build |
| examine, inspect (loosely) | examine, check (per approved sense) |
| indicate | show |
| observe | look at, see |
| comply with, adhere to | obey, follow (the rule) |
| facilitate | help, make easier |
| eliminate | remove, prevent |
| minimize / maximize | decrease / increase |
| endeavour, attempt | try |

| subsequent to, following | after |

| in order to | to |

| in conjunction with | with |

|---|---|

## Phrasing / hedging to cut
| Avoid | Use |
|---|---|
| and/or | and, or (choose one, or reword) |
| it is recommended that | you must, do X |
| it is necessary to | you must |
| in the event of a failure | if X fails |
| at this point in time | now |
| a sufficient number of | enough |
| take into consideration | think about, consider |
| make an adjustment to | adjust |
| give assistance to | help |

## Reminders
- Do not replace a **technical name** or **technical verb** (e.g. *actuator*, *solder*,
  *torque*, *de-ice*). STE keeps domain terms.
- After substituting, re-check verb form (no -ing, simple tenses only) and sentence length.
- One concept = one word. Once you choose *start*, do not also use *begin* for the same
  action in the same document.
